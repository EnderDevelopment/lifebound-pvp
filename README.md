# LifeBoundPVP

LifeBoundPVP is a Minecraft plugin designed for Bedrock Edition that enhances PvP gameplay by introducing a life system. Players start with 3 lives, and each death reduces their life count by 1. When a player's lives reach zero, they enter spectator mode, allowing them to fly but not pass through walls. Spectators remain invisible to living players and can use a compass to teleport near living players. The plugin individually manages the lives of multiple players, ensuring a balanced and engaging PvP experience.

## Install

1. Download the plugin JAR file from the releases section.
2. Place the JAR file in the `plugins` folder of your Minecraft Bedrock Edition server.
3. Restart the server to load the plugin.

## Use

1. Players start with 3 lives.
2. Use the `/life` command to check your remaining lives.
3. When a player dies, their life count decreases by 1.
4. If a player's lives reach zero, they enter spectator mode.
5. In spectator mode, use the compass to teleport near living players by using the `/spectate <player>` command.
